# Projet Ville

Une ville européenne fictive, réaliste et entièrement explorable pour Roblox : un jeu de **roleplay urbain** contemporain (2026) où presque tous les bâtiments s'ouvrent, où les intérieurs sont meublés et interactifs, et où la ville **fonctionne** : électricité, eau, télécoms, informatique, transports et économie, tous reliés.

> Nom de code : **Projet Ville**. Le nom définitif de la ville sera choisi plus tard.
